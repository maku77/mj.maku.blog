嵌張チーで1つ外側が切られたらその筋は安全
----

ケースとしては多くありませんが、次のような嵌張チーが入り、1つ外側の {{< mj 3p >}} が切られた場合は、その筋の {{< mj 6p >}} や {{< mj 9p >}} はほぼ通ります。

{{< mj-center "5ph4p6p" >}}

これは、どのような形からこのチーを入れたら {{< mj 6p9p >}} 待ちが残るかを考えてみると分かります。

- {{< mj 3p6p >}} あるいは {{< mj 6p9p >}} の両面待ちが残る形
  - 元の形が {{< mj 3p4p4p5p6p >}} であれば、{{< mj 5p >}} であがっているはずなのでありえない。
  - 元の形が {{< mj 3p4p6p7p8p >}} であれば、{{< mj 5p >}} であがっているはずなのでありえない。
- {{< mj 6p >}} のカンチャン待ちが残る形
  - 元の形が {{< mj 3p4p5p6p7p >}} であれば、{{< mj 5p >}} であがっているはずなのでありえない。
- {{< mj 6p >}} のシャボ待ちが残る形
  - 元の形が {{< mj 3p4p6p6p6p >}} であれば、{{< mj 5p >}} であがっているはずなのでありえない。

ただし、強引な三色やイッツーのための {{< mj 4p5p6p >}} チーの場合は {{< mj 6p9p >}} 待ちが残る可能性はありますが、であれば {{< mj 3p >}} はもう少し前に切っていそうです。


その他の筋の危険度は？
----

このように、{{< mj 6p9p >}} はほぼ安全と言えますが、{{< mj 1p4p7p >}} や {{< mj 2p5p8p >}} は必ずしも安全とは限りません。
下記のように多数のパターンが考えられます（とはいえ {{< mj 1p >}} はかなり安全）。

- {{< mj 1p1p3p4p6p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 1p >}} 待ち
- {{< mj 2p3p3p4p6p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 1p4p >}} 待ち
- {{< mj 3p4p5p6p6p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 4p7p >}} 待ち
- {{< mj 3p4p6p6p8p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 7p >}} 待ち
- {{< mj 1p3p3p4p6p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 2p >}} 待ち
- {{< mj 3p3p4p4p6p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 2p5p >}} 待ち
- {{< mj 3p4p6p6p7p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 5p8p >}} 待ち
- {{< mj 3p4p6p8p8p >}} から {{< mj 5ph4p6p >}} チー {{< mj 3p >}} 切りで {{< mj 8p >}} 待ち


逆側の筋は？
----

ちなみに、上記は鳴いた牌にかかる方向の筋が安全という理屈でしたが、逆方向の筋も通常安全です。
例えば、

{{< mj-center "7ph6p8p" >}}

という嵌張チーからの {{< mj 5p >}} 切りの場合、{{< mj 8p >}} だけでなく {{< mj 2p >}} も安全です。
仮に、{{< mj 1p3p5p6p8p >}} の形から {{< mj 7p >}} をチーして {{< mj 5p >}} を切ると {{< mj 2p >}} 待ちなりますが、イーシャンテンでこの形であれば {{< mj 8p >}} はもっと前に切っています。
もちろん、1巡おいてから {{< mj 5p >}} 切りであれば、リャンカン残しからの {{< mj 2p >}} 待ちが十分に考えられます。
{{< mj 2p2p5p6p8p >}} の形であれば {{< mj 7p >}} チーから {{< mj 5p >}} 切りで {{< mj 2p >}} のシャボ待ちに受けられますが、こんなヒッカケをするために {{< mj 8p >}} を温存することはまずありません。
まぁ、そもそもこんな不自然な形のチーはほとんど出ないですね。
{{< mj 7ph5p6p >}} の形で鳴いて {{< mj 8p >}} を切ればよいだけのなので。


おまけ: 嵌張チーの2つ外側の牌が切られたら？
----

{{< mj "5ph4p6p" >}} チーから、そのメンツの 2 つ外側の牌である {{< mj 2p >}} が切られた場合は、その筋の {{< mj 5p8p >}} が安全であるという理屈は成り立ちません。

- {{< mj 2p4p6p6p7p >}} から {{< mj 5ph4p6p >}} チー {{< mj 2p >}} 切りで {{< mj 5p8p >}} 待ち
- {{< mj 2p4p4p6p6p >}} から {{< mj 5ph4p6p >}} チー {{< mj 2p >}} 切りで {{< mj 5p >}} 待ち
- {{< mj 2p4p6p8p8p >}} から {{< mj 5ph4p6p >}} チー {{< mj 2p >}} 切りで {{< mj 8p >}} 待ち

これは単純に 1 つのリャンカン形が解消されただけと捉えてください。
つまり、{{< mj 2p >}} 以外のピンズはいずれも安全とは言えません。


おまけ: 嵌張チーの内側の牌が切られたら？
----

{{< mj "5ph4p6p" >}} チーから、そのメンツに含まれている {{< mj 4p >}} が切られた場合は、その向かい側の牌である {{< mj 6p >}} の筋が比較的安全です。

- {{< mj 4p4p4p5p6p >}} であれば、もともとテンパイしているので {{< mj 5ph4p6p >}} チーはないはず。
- {{< mj 1p2p4p4p6p >}} であれば、{{< mj 1p >}} 切りになるはず（というか無駄なペンチャンは残っていないはず）。
- {{< mj 3p3p4p4p6p >}} であれば、{{< mj 3p >}} 切りで {{< mj 2p5p >}} の両面に受けるはず。
- {{< mj 2p4p4p4p6p >}} という形はあり得るが、これでテンパイであればシャボに受けておく可能性がある。
- {{< mj 4p4p6p7p8p >}} から {{< mj 5ph4p6p >}} チーの食い伸ばしは、バレバレのホンイツなどであり得る。
- {{< mj 4p4p5p6p7p >}} から {{< mj 5ph4p6p >}} チーの食い伸ばしであれば、{{< mj 7p >}} 切りになる。
- {{< mj 4p4p6p6p6p >}} であればもともとテンパイしている。

{{< mj 3p6p9p >}} 以外のピンズ待ちは普通にありえます。
筋の {{< mj 7p >}} も安全とは言えません。

- {{< mj 4p4p6p6p8p >}} から {{< mj 5ph4p6p >}} チー {{< mj 4p >}} 切りで {{< mj 7p >}} カンチャン待ち
- {{< mj 4p4p6p7p7p >}} から {{< mj 5ph4p6p >}} チー {{< mj 4p >}} 切りで {{< mj 7p >}} シャボ待ち
